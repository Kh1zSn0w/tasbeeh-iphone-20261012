# Tasbeeh

Simple offline native iPhone counter, iOS 15 or newer. Tap to count, undo the last tap, reset the session while keeping today's total. Long press the title or use the ellipsis to adjust today's total. Counts are stored on device.

GitHub Actions compiles an ARM64 IPA with an ad-hoc signature. Sideloadly or another personal signing tool must re-sign it for installation. No Apple credentials are included.
